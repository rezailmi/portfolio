## Findings considered and rejected

- **ScaryNumbers god-component refactor** (`components/scary-numbers.tsx`, 724 lines, DOM-attribute state, duplicated mouse/touch paths): real debt, but behavior-preserving rework of intricate drag math with zero tests is high risk for low user value. The one actual bug inside it (dropzone index off-by-one) is fixed by plan 008. Revisit only if the demo needs feature changes.
- **`asChild` as a correctness bug**: refuted — all 25 sites target shadcn wrappers that implement `asChild` via `@radix-ui/react-slot`, which is installed and wired. Reclassified as idiom-convergence debt (plan 007). Do not re-audit as a bug.
- **`bun audit` advisories** (45 at planning time): all in build-time/dev dependency chains (eslint tooling, next-sitemap globbing, gray-matter→js-yaml parsing the repo's own content). No reachable runtime exposure on a static site. Re-check after plan 003 shrinks the tree.
- **`/base` and `/edit` orphan routes**: publicly reachable, unlinked demo/playground pages. Left as a maintainer decision (may be deliberate hidden playgrounds) — gate or delete if unwanted; plan 002 already keeps `/edit`'s made-refine code out of other routes' bundles.
- **CONFIRMED PRE-EXISTING BUG (2026-07-03 E2E pass)**: `/edit` returns 500 both locally and on live production (rezailmi.com/edit) — made-refine's `DirectEditDemo` calls `useDirectEditState()` with no `DirectEditProvider` anywhere in the tree. Not introduced by the refactor (verified against live prod). Fix upstream in made-refine or wrap/remove the route.
- **`forwardRef` modernization** (~36 sites in `components/ui/`, unnecessary under React 19): valid but pure churn in generated files; do it opportunistically if those files are ever regenerated from a React-19 shadcn registry.
- **`SITE_URL` vs `NEXT_PUBLIC_SITE_URL` env split** (`lib/content.ts:30` + `next-sitemap.config.js` vs `app/layout.tsx:23`): noted in plan 004's maintenance notes; touching deployment env config wasn't worth its own plan.
- **`.babelrc` forcing Babel in production builds** (exists for made-refine's dev-only plugin): noted in plan 002's maintenance notes; removable only if made-refine offers a non-Babel integration.
- **Not audited**: `made-refine` package internals; deep security pass (no server actions or API routes exist — static content site).
